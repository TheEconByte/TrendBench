# 현재 제품 기준

확정 기준일: 2026-09-18. 기존 방향 분석 11번은 결정 과정의 기록이며, 현재 범위는 이 문서를 따른다.

## 대상과 목적

서울에서 음식점·카페 창업을 준비하는 예비 창업자. 공개 상권 지표와 사용자의 가정을 구분하여 초기 필요자금, 부족자금, 월 운영수지와 상환 부담을 이해하도록 돕는다.

## 첫 구현과 전체 MVP

첫 구현은 사용자 가정 입력·계산·저장이다. 전체 MVP는 상권 탐색, 계획 작성, 자금 후보 확인, 시뮬레이션, 저장 결과 비교를 포함한다. 화면의 사용자 순서와 개발 순서는 같을 필요가 없다.

| 사용자 단계 | 입력 | 출력 |
|---|---|---|
| 상권 탐색 | 자치구·상권·업종 | 가용 분기·관측 지표·출처·자료 부족 상태 |
| 계획 작성 | 초기 비용·예비금·자기자금·월매출·고정비·변동비 | 부족자금·운영수지·운영비 충당 매출 |
| 자금 후보 | 사업단계·시기·용도·공고별 추가 조건 | 검토 후보·미충족·미확인·종료 사유 |
| 시뮬레이션 | 무차입 또는 확인한 가정 대출 조건 | 상환 일정·잔여현금·초기 자금 충족·3개 시나리오 |
| 저장·비교 | 계획명·수정한 가정 | 초안·불변 결과·결과 2개 비교 |

상권 탐색은 공개, 개인 계획의 서버 저장은 로그인 후 제공한다. 후보가 없거나 매출 자료가 부족해도 사용자 가정 기반 계획은 계속할 수 있다.

## 범위 제한

- 첫 데이터 연결은 서울 한식(CS100001)·커피음료(CS100010). 다른 업종은 가용성과 사용자 필요를 확인한 뒤 추가한다.
- POS·매출파일 업로드·기존 점주 운영 분석·익명 peer benchmark는 제외한다.
- 예측 ML·종합 안정성 점수·신용 판단·자동 대출 승인·최적 조달 조합은 제외한다.
- 주소 자동 상권 매핑·지도·전국 확대·자동 PDF·관리자 대시보드는 보류한다.
- 가입 이메일 전달, 상품 검수 책임, 배포·백업은 출시 전에 별도 확인한다.

## 아직 확인이 필요한 것

매출의 시간 단위와 점포당 매출 분모, 최신 데이터 릴리스, 운영용 지원사업 조건은 확정되지 않았다. 해당 결과를 임의 생성하지 않는다. 2026-09-09에 조회한 공고 상태를 오늘의 접수 상태로 재사용하지 않는다.

정확한 식·상태·입력 제약은 [기술 설계](12_Simplified_MVP_Technical_Plan.md), 실제 확인 범위는 [검증 보고서](13_Data_API_Feasibility_Verification.md)를 따른다.
